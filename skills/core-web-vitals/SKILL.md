# Core Web Vitals

Optimize for real-user experience.

- Reduce server response time and unnecessary client JavaScript.
- Optimize images and use responsive dimensions.
- Lazy-load non-critical media without hiding important crawlable content.
- Reserve image/chart/ad space to prevent layout shifts.
- Avoid long main-thread tasks and excessive hydration.
- Optimize fonts and third-party scripts.
- Cache stable resources appropriately.
- Keep mobile navigation, charts, tables, and ads usable.
- Measure representative pages rather than optimizing only the homepage.
- Do not sacrifice useful content or accessibility solely for speed scores.

After performance changes verify Core Web Vitals, mobile UX, rendering, ads, charts, and SEO-critical HTML.
