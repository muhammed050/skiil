# Core Web Vitals

Optimize LCP through server response, critical rendering, hero assets, and image delivery. Optimize INP through reduced client JavaScript and efficient event handlers. Prevent CLS by reserving dimensions for images, ads, charts, and dynamic content.

Also inspect fonts, caching, compression, code splitting, hydration, API latency, database queries, image formats, lazy loading, and unnecessary client-side work.

Measure representative home, stock, company, category, article, and chart-heavy pages on mobile and desktop.

Never improve synthetic scores by removing important user content or financial functionality. Validate that SEO metadata, charts, prices, navigation, and ads still behave correctly.
