# Entity SEO

Maintain one consistent identity for each entity across URLs, titles, structured data, internal links, and content.

Validate:
- company name
- ticker
- exchange
- sector
- stable identifier
- canonical URL
- source relationship

Example relationship:
THYAO → Türk Hava Yolları → BIST listing → sector → related news.

Never mix data between similar company names or symbols. Keep aliases consistent and use redirects/canonicalization when duplicate entity URLs exist.

Use entity relationships to power relevant internal links and structured data, not artificial link networks.
