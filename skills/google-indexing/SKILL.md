# Google Indexing

For important URLs verify: intended status → accessible → crawlable → not accidentally noindex → canonical correct → rendered content available → sitemap where appropriate → internal links.

Do not claim indexing merely because a URL is in a sitemap. A sitemap is discovery support, not an indexing guarantee.

Investigate patterns such as discovered-not-indexed, crawled-not-indexed, duplicate/canonicalized, soft 404, blocked by robots, noindex, redirect, server errors, and rendering failures.

Prioritize root-cause fixes. Avoid mass publishing thin, empty, duplicate, invalid, or orphan URLs.

When Search Console access exists, use URL Inspection, Page Indexing, Sitemaps, and performance signals. Record evidence, affected URL pattern, root cause, fix, and validation.
