# Google Indexing

For every important public page:
- Return the correct HTTP status, normally 200 for a valid indexable page.
- Do not accidentally apply noindex, password protection, robots blocks, or broken canonical tags.
- Include the canonical URL in the XML sitemap when appropriate.
- Ensure the page is discoverable through meaningful internal links.
- Ensure server-rendered or crawlable HTML contains the important content and links.
- Avoid soft 404 pages and duplicate URL variants.
- Keep redirects short and intentional.
- Do not create indexable empty, thin, filter, search, admin, or user-private pages.
- Monitor indexing status through Search Console when connected.

Indexing is not guaranteed. Optimize discovery and eligibility; never use deceptive techniques or fake Google signals.
