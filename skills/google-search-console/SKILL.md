# Google Search Console

When access is available inspect URL Inspection, Page Indexing, Sitemaps, Core Web Vitals, HTTPS/security, manual actions, and search performance.

Do not infer indexing status from sitemap presence alone.

For every issue record:
- exact URL or URL pattern
- evidence
- likely root cause
- corrective action
- validation method

Separate technical indexing problems from ranking/content problems. Prioritize systemic patterns over isolated URLs, but validate representative examples before mass changes.

Never claim Google has indexed a page without evidence.
