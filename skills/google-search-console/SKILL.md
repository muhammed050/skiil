# Google Search Console

Use connected Search Console data when available.

Monitor:
- indexed and non-indexed URL patterns
- indexing errors and exclusions
- sitemap processing
- search queries
- impressions
- clicks
- CTR
- average position
- country/device patterns
- Core Web Vitals reports when available

Prioritize issues by impact and affected URL count.

Never claim a URL is indexed without evidence. Never fabricate Search Console metrics. Distinguish Search Console data from analytics data.

When diagnosing indexing, inspect the exact URL and its canonical, robots, status code, sitemap presence, internal links, and content quality.
