# Image Indexing

- Ensure important images are exposed in crawlable HTML and have stable public URLs.
- Do not block image paths or image CDN hosts unintentionally in robots.txt or X-Robots-Tag.
- Use descriptive filenames when practical.
- Add accurate, concise alt text that describes the image; never stuff keywords.
- Provide width and height and responsive image variants.
- Use WebP/AVIF when compatible without harming discoverability or quality.
- Lazy-load below-the-fold images, but ensure important images are still discoverable in HTML.
- Keep canonical pages and their important images publicly accessible.
- Maintain an image sitemap for important crawlable images when useful.
- Use relevant surrounding text, captions, and headings so Google can understand image context.
- Do not generate fake charts, logos, company images, or market visuals.
- Do not rely on CSS backgrounds for important indexable imagery.

Validate image HTTP status, robots access, CDN access, HTML discovery, alt text, dimensions, and sitemap inclusion. Image indexing and ranking are never guaranteed.
