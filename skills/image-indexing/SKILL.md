# Image Indexing

Important images must be fetchable and discoverable.

Check valid image URLs, crawlability, robots.txt, X-Robots-Tag, CDN access, JavaScript rendering, responsive image markup, srcset, picture, dimensions, and image sitemap opportunities.

Use descriptive filenames, accurate natural alt text, relevant captions and surrounding text. Never keyword-stuff alt text or invent image descriptions.

Do not lazy-load critical images in a way that prevents discovery. Use responsive delivery and modern formats when appropriate while preserving crawlable source URLs.

Image sitemap entries can improve discovery but never guarantee Google Images ranking.

Validate representative stock logos, company images, chart images, article images, OG images, and decorative images separately.
