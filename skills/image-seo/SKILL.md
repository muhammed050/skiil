# Image SEO

- Use descriptive filenames when practical.
- Write accurate human-readable alt text; do not stuff keywords.
- Add captions when they improve understanding.
- Use correct image dimensions and responsive srcset/sizes.
- Prefer efficient formats such as WebP or AVIF when appropriate.
- Compress without damaging important chart or text readability.
- Use stable public image URLs.
- Provide meaningful surrounding page context.
- Use original or properly licensed images.
- Avoid generic stock imagery when a specific visual adds value.
- Important images should be discoverable in HTML rather than only hidden in CSS.
- Do not create fake company logos, charts, or financial visuals.

Audit accessibility, crawlability, performance, licensing, and relevance together.
