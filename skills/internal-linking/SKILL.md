# Internal Linking

- Link pages when the destination genuinely helps the user.
- Connect stock pages to company, sector, related stock, news, and educational pages where relevant.
- Use descriptive natural anchor text.
- Ensure important pages have inbound internal links and are not orphaned.
- Avoid huge automated link blocks and irrelevant links.
- Avoid repeating the same anchor unnaturally.
- Keep links crawlable HTML links.
- Repair broken internal links and remove links to deleted pages.
- Use canonical destination URLs.
- Build useful hub pages for sectors, markets, and educational topics.

Priority: user navigation first, crawl discovery second, SEO benefit third.
