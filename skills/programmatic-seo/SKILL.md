# Programmatic SEO

Use templates only when each generated page satisfies a real user intent.

- Every entity page must contain verified entity-specific data.
- Avoid thousands of pages that differ only by ticker, city, or one swapped sentence.
- Do not publish empty or incomplete pages just to capture keywords.
- Use stable canonical URLs and include only quality indexable pages in sitemaps.
- Add meaningful internal links and useful related entities.
- Include timestamps for changing market data.
- Avoid doorway pages and near-duplicate category combinations.
- Generate pages only for valid stocks, companies, sectors, and supported intents.
- Provide useful summaries, tables, charts, explanations, and context where data exists.
- If required data is missing, show an honest unavailable state or do not publish the page.

Measure page usefulness, indexing quality, engagement, duplication, and crawl waste rather than page count alone.
