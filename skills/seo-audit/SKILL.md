# SEO Audit

Audit representative page types: homepage, stock page, company page, sector page, article/news page, category page, image-heavy page, and error page.

Check:
- HTTP status and redirects
- robots.txt and noindex
- canonical URLs
- sitemap inclusion
- title and meta description
- headings and content quality
- internal links and orphan pages
- structured data validity
- image crawlability, alt text, dimensions, and performance
- mobile UX and Core Web Vitals
- duplicate and thin content
- financial-content safety
- source and timestamp transparency
- AdSense-safe ad placement

Classify findings as Critical, High, Medium, or Low and provide the smallest practical fix.

Never report an issue as fixed without verification.
