# SEO Audit

Audit in this order:
1. HTTP/status/indexability
2. robots.txt
3. sitemap
4. canonical consistency
5. titles/descriptions
6. rendered content
7. internal links and orphan pages
8. structured data
9. duplicate/thin programmatic content
10. image discovery and SEO
11. Core Web Vitals/mobile UX
12. financial-data integrity
13. trust and advertising transparency
14. Search Console evidence

Every issue must include severity (critical/high/medium/low), affected URL or pattern, evidence, root cause, exact fix, and validation method.

Do not recommend changes based solely on generic SEO assumptions when the implementation can be inspected. Test representative templates before mass changes.

Definition of done: fixes are implemented, generated URLs and metadata are validated, financial logic is intact, and no deceptive SEO behavior was introduced.
