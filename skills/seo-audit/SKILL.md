# SEO Audit

## Scope
Audit crawlability, indexability, rendering, content, URLs, metadata, schema, images, internal links, programmatic pages, performance, financial integrity, trust, ads, and Search Console evidence.

## Audit Order
1. status/indexability
2. robots/noindex
3. sitemap
4. canonical
5. metadata/OG
6. rendered primary content
7. internal links/orphans
8. structured data
9. duplicate/thin programmatic pages
10. image discovery/SEO
11. Core Web Vitals/mobile
12. financial data integrity
13. trust/advertising transparency
14. Search Console

## Severity
Critical = blocks important crawling/indexing or creates serious data/deception risk.
High = affects a major template or large URL family.
Medium = meaningful localized issue.
Low = refinement.

## Evidence Standard
Every finding must contain exact URL/pattern, observed evidence, root cause, affected scope, exact fix, validation method, and expected result. Generic SEO advice is not a finding.

## Sampling
Inspect representative homepage, stock, company, sector, market, article/news, filter/search, pagination, parameter, redirect, 404, and private routes before recommending mass changes.

## Change Control
Never mass-publish, mass-delete, mass-noindex, or mass-redirect without sampling and URL-pattern analysis. Prefer reversible changes.

## Final Verification
Recheck status, robots, canonical, sitemap, metadata, rendered content, schema, links, images, mobile UX, performance, and financial functionality after implementation. Record unresolved risks separately.
