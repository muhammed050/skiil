# Structured Data

- Prefer JSON-LD.
- Use only schemas genuinely applicable to the page.
- Keep structured data consistent with visible content.
- Useful types may include Organization, WebSite, BreadcrumbList, Article, NewsArticle, FAQPage, and Dataset when eligibility and content support them.
- Never fabricate ratings, reviews, authors, dates, prices, FAQ answers, or aggregate values.
- Do not mark up hidden content solely to obtain search features.
- Validate JSON-LD syntax and required properties after changes.
- Keep entity names, URLs, dates, and images accurate.
- Remove schema when the page no longer qualifies.

Structured data helps machines understand a page; it does not guarantee rich results or higher rankings.
