# Technical SEO Quality

For every indexable page:
- Use a unique useful title, meta description, canonical URL, language, Open Graph metadata, and appropriate social metadata.
- Keep important pages crawlable and indexable; prevent accidental noindex, robots blocks, broken rendering, and duplicate URLs.
- Keep sitemap URLs canonical, public, indexable, and returning successful responses.
- Use JSON-LD only when it matches visible content.
- Build meaningful internal links and breadcrumbs.
- Optimize images, JavaScript, fonts, caching, server response, Core Web Vitals, and mobile layout.
- Use clean stable lowercase URLs.
- Avoid thin programmatic pages and parameter-generated duplicates.
- Ensure 404/error states are real errors and not misleading 200 pages.

Validate canonical, robots, sitemap, indexability, structured data, internal links, mobile rendering, performance, and broken links after changes.
